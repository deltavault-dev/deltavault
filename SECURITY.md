# Security

Do not post API keys, private keys, recovery phrases or exploitable vulnerabilities in public issues. Report sensitive findings privately to the repository owner using a verified contact or GitHub private vulnerability reporting when enabled. No project security email has been supplied.

This repository is not presented as audited. Wallet connection requests a public account; deployed trading contracts and transaction execution are outside this implementation. Market data depends on external service availability and accuracy. Configured liquidity figures are not onchain balances.

Keep CoinGecko credentials in server bindings. Review upstream dependency advisories before production changes. A successful build or CI result does not establish contract safety.
